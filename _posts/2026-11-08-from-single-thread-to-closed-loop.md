和 AI 协作久了，我越来越觉得，AI应该成为每个人的第二大脑——这是我们和AI合作的基石。

其中，最核心的点是，整个机制要形成一个可反馈的闭环，而不是单线程的问答。

我顿悟到这一点，在今年的上半年复盘。我把 1–6 月的 258 条 flomo 记录一次性丢给 AI，它读完指出了一件看似微不足道的小事：同一个问题，它在 3 月和 4 月已经点破过我两次，我每次都很认同，然后……什么也没变。

因为那时候，我和AI的对话是单线程的。对话一关，回应就停在聊天记录里。下次开新窗口，就不再记得从前的许诺，也没有人去核对后来有没有改变。

为了补上这一环，过去两个多月我搭了一套闭环系统。在这里分享一些设计和踩过的坑，比如：

1. AI 每次开工前，应该知道我的什么？
2. 让文件能够自动更新迭代，需要哪几个要素？
3. 这套东西在哪里会失效？

## 01. Introduction

整套系统的 read path 是三份文件，写给所有 AI agent 看：

- soul.md：我是谁。职业、家庭结构、生活和认知两套北极星、长期决策原则，还有一节「最容易被误读的地方」。
- ai.md：我们怎么合作。我对我的AI的定位，识别任务模式，基本沟通与判断规则，自主边界与工程纪律等。
- memory.md：最近发生了什么。当前选择、近期事实、观察和反例，重要条目都带复查时间。

入口写在 AGENTS.md 和 CLAUDE.md 这类全局规则文件里，Codex 和 Claude Code 开工前都会先读这三份。

为什么要写三个文件，而不是一个呢？

因为三类信息的更新速度差太多：

身份（几年一变）→ 协作方式（几个月一变）→ 近况（每周都在变）

放在一份里，每改一次近况都要碰到身份那部分。

另外还补了一条规则：三份文件每次都读，但个人模型只在人生选择、价值取舍、自我复盘这类任务里调用。不然很容易出现 AI 帮你 debug 时，顺手分析你性格的情况。

## 02. Write Path 的三个核心要素

read path 解决的是「AI 知道我是谁」。这是个静态的事情。

让文件真正动起来的是 write path，也就是通过定期复盘，让AI去更新上面的三个文档。我自己的体会是，它要做好三件事：

### 1. 节奏

- 每月 1 日：定时任务启动上个月的完整复盘
- 每季度：汇总三份月报，看跨月趋势
- 每年 1 月 2 日：年度复盘

最开始是我只做季度复盘，这个月我加了月度复盘。我觉得这样的密度更适合我。

memory 里每条重要内容要带复查时间：把一次判断拆成「现在记下」和「到期再看」两步，到点了必须重新确认、改写或归档，不能自动变成永久规则。

### 2. 证据

复盘必须同时看三类证据：

- 主观记录：flomo 里我记了什么
- 客观行动：代码和文档显示我实际做了什么
- 外部结果：发布、交付和别人的反馈

要给AI尽可能完整的context。

### 3. 规则

AI 很擅长解释的。一次没做的事，它能讲成回避；一段情绪，它能讲成人格。这类解释一旦直接写进 soul，观察就变成了对我的定义，之后每次协作，我都会被这个定义重新解读一遍。

所以写回要分层：

单次事件（观察）→ 跨时间、跨情境反复出现且检查过反例（模式候选）→ 价值和长期优先级（只能由我本人认领）

新内容默认进 memory，影响合作方式的才改 ai.md，动 soul.md 的门槛最高。

每次复盘的最后一步，是生成三份文件的修改建议（diff）。我逐条看，批准后先存一份旧版本 snapshot，再改正文、写 changelog。

## 03. Use Case

举一个形成闭环的例子。

我做过一个资产配置看板，Q3 复盘发现自己很少打开。AI 给的首选解释是节奏错配：看板按天更新，但我的配置策略是低频的，每天打开它本来就没必要。

接下来的过程是这样的：

Q3 复盘发现很少用 → 提出「节奏错配」假设 → 10 月初改成每周一个入口、只在工作日运行 → 10 月中旬周末集中使用 → 写进 memory，旁边记上反例 → 等 Q4 复盘再检验

如果下个季度使用又掉下去，这个解释就得改。

这样，AI会和我一起，找到最适合我的看板配置方式。

## 04. 它在哪里会失效？

### 1. 证据

也就是context，这是最核心的问题。代码和文档主要记录的是你做了什么，体验、关系和起心动念要靠持续的记录。我主要是靠 flomo 语音，每天至少会记录1条。flomo现在的MCP也很方便，可以让agent自动读取。

哪一类证据薄，那一块就更新得慢。这时候宁可如实写「证据不足」，也不要用推断去补齐。

### 2. 审批

修改建议堆着不看，write path 就断了，系统会退回成一份越来越旧的设定。

给它加上定期回顾和明确的批准人，它才会不断更新迭代。

/


最适合自己的才是最好的。每个人都需要自己动手搭自己的第二大脑，让它适应你、适合你，成为你亲密无间的伙伴。会有惊喜发生的。
